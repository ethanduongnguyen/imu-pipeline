# IMU Pipeline

Learning IMU data acquisition and processing using an ESP32 and MPU6050. Also includes translations of research-grade IMU processing pipelines from MATLAB into Python
## Hardware

- ESP32
- MPU6050

## Roadmap

- [x] Read accelerometer
- [x] Read gyroscope
- [X] Timestamped CSV logging
- [X] Python serial logger
- [X] Sensor calibration
- [ ] Signal filtering
- [ ] Orientation estimation
- [ ] Feature extraction
- [ ] Event detection

## Goals

Build a complete IMU pipeline that will eventually support human-in-the-loop annotation framework for wearable robotics research
