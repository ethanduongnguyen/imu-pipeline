# IMU Learning

Learning IMU data acquisition and processing using an ESP32 and MPU6050

## Hardware

- ESP32
- MPU6050

## Roadmap

- [x] Read accelerometer
- [x] Read gyroscope
- [ ] Timestamped CSV logging
- [ ] Python serial logger
- [ ] Sensor calibration
- [ ] Signal filtering
- [ ] Orientation estimation
- [ ] Feature extraction
- [ ] Event detection

## Goals

Build a complete IMU pipeline that will eventually support human-in-the-loop annotation framework for wearable robotics research
